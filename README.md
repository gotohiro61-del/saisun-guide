# 引っ越し採寸ガイド(saisun-guide)

エバースホールディングス原状回復事業部のサービスサイト。
空室に設置するオリジナルメジャーのQRコードから飛ぶ「引っ越し採寸ガイド」ページ。

背景・方針は [CLAUDE.md](CLAUDE.md) を参照。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 公開ページ本体。JavaScriptゼロ・外部依存ゼロの静的1ページ |
| `design/mockup-v1〜v5.html` | 検討過程のモックアップ(v5.2 が index.html の元) |

ブラウザで `index.html` を開けばそのまま表示できます。ビルド不要。
